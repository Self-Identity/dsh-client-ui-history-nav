# Changelog

All notable changes to this package are documented here. Versions follow
[semantic versioning](https://semver.org/).

## 1.5.0 — 2026-10-19

- Bilingual plugin metadata: `locale/zh.json` and `locale/en.json` now carry
  the card title and description, and the display follows the client language.
- `repository`, `homepage`, `bugs`, `author` and `engines.dsh` are declared so
  the package can be published and listed in the plugin market.

## 1.4.0 — 2026-10-19

- Refreshing asks for confirmation while the selected session is still
  replying or executing.

## 1.3.0 — 2026-10-18

- 26px compact buttons and a page refresh action.

## 1.2.0 — 2026-10-18

- Back and forward unified into a single pill at the right of the desktop menu
  bar, at the same position on session and panel pages.

## 1.1.0 — 2026-10-18

- Initial back / forward pill for global panel pages, with one shared history
  stack for sessions and panels.
